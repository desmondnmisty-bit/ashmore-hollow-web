# Ashmore Hollow (browser build)

Play: https://desmondnmisty-bit.github.io/ashmore-hollow-web/

This is a Godot 4 web export. The first load is large (about 370 MB). Use a desktop browser (Chrome, Edge, or Firefox). Click inside the game once to turn on sound.

The game `.pck` is split into parts under GitHub's 100 MB file limit and joined in the page loader. Source lives in the private `ashmore-hollow-godot` repository.
